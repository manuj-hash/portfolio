## ⚡ Core Concept & Aesthetic

Unlike standard portfolio templates with static profile cards and plain boxes, **MANUJ DIGITAL ENVIRONMENT** is architected as an immersive cybernetic command center:

- **Color Palette**: Deep Black / Charcoal (`#030407`, `#07090E`), Electric Cyan (`#00F2FE`), Electric Violet (`#8B5CF6`), and Terminal Emerald (`#10B981`).
- **Typography**: Clean, technical font pairing (`Space Grotesk` + `JetBrains Mono` + `Inter`).
- **Interactive Spatial Synapse Mesh**: A real-time 2D Canvas node graph where physics-connected nodes represent software, AI, and cryptographic subsystems.
- **Glowing Laser Thread**: Hovering over keywords (`DEVELOPER`, `AI ENGINEERING`, `CYBERSECURITY`, `PQC`) casts an animated laser thread connecting the text directly to the active telemetry panel.
- **Cinematic Bootloader**: A precise 2.0-second operating system initialization sequence with bios integrity checks, progress diagnostics, and smooth transition.
- **Synthesized Audio Telemetry**: Native Web Audio API sound synthesis (subtle boot chimes, laser chirp blips, mute/unmute control, zero external MP3 dependencies).
- **Interactive Terminal Console**: Built-in developer command line (`Ctrl + K` or Terminal HUD) supporting commands like `help`, `skills`, `projects`, `sih`, `pqc`, `contact`, `clear`.

## 🚀 Running the Project Locally

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Commands

```bash
# 1. Install dependencies (already executed)
npm install

# 2. Launch local development server
npm run dev

# 3. Build optimized production bundle
npm run build

# 4. Preview production build locally
npm run preview
```

The dev server will run at `http://localhost:5173`.

## 🛰️ Deployment Guide

### Deploying to Vercel / Netlify
1. Push repository to GitHub.
2. Import repository in [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
